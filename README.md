# 情境画像

一个无第三方依赖的静态网页：可把原始情境题交给 AI，再粘贴其选择；也可在页面亲自完成 36 题。画像均在浏览器本地生成，答案不会发送到服务器。

## 启动

在项目目录运行：

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/>。请通过本地 HTTP 服务访问，不要直接双击打开 `index.html`，因为浏览器需要读取题目文件并加载 ES 模块。

## 使用

1. AI 作答：点击“复制全部题目”并发送给 AI，再把 AI 的完整回答粘贴到答案框，点击“生成画像”。
2. 个人作答：展开“我也来做题”，按第一倾向为 36 题逐题单选，再点击“生成个人画像”。折叠问卷不会清除已选答案；“重置选择”只清除个人问卷答案。
3. 任一方式生成的画像都可展开查看五维分值、原型距离、计算说明和 36 道题的原文与选择，结果会标明来源。

剪贴板不可用时，页面会显示完整题目文本，可手动选择复制。AI 答案有缺漏、重复或歧义时会提示修正。修改某一种作答只会清除当前显示的同来源旧画像，不会清除另一种作答或其已显示画像；AI 的“清空”和个人问卷的“重置选择”分别只重置各自输入。

### 支持的回答格式

每题必须有且只有一个 A、B、C 或 D。可使用以下任一格式：

```text
1.A
2.C
...
36.D
```

```text
Q1: A
Q2: C
...
Q36: D
```

也支持 Markdown 列表或代码围栏、每题单选后附解释，以及恰好 36 行的纯选项序列：

```text
- 1. **A**
- 2. **C**
```

JSON 可用 `1` 或 `Q1` 作为题号键，也可放在 `answers` 对象中。混合多选、重复题号、无效题号和缺题会被拒绝。

## 计算方式与边界

- 第 1–30 题形成探索（E）、风险（R）、自主（A）、理想主义（I）、规划稳定（P）五项 0–100 指标；题目映射以 `评分规则.txt` 为准。第 4、16 题不进入这五项计算。
- 将五维画像与 18、23、30、38、47、58 岁六个内部原型比较，使用加权欧氏距离，权重依次为 E 0.24、R 0.24、A 0.16、I 0.16、P 0.20。先取距离最近的原型，再从它的相邻年龄原型中选距离较近者；两者之间按距离倒数加权插值。参与插值的原型距离为零时，直接采用该原型年龄，结果四舍五入。
- 第 31–36 题只生成六项独立行为风格指标，不参与心理年龄计算。
- 分项年龄和趣味指数是额外娱乐展示。自主倾向不转换为年龄。

年龄原型是测试内部娱乐模型的标签，不是实际年龄。五维、行为风格与趣味分均为 0–100 的相对倾向指标，不表示好坏、能力或成熟度，也不是心理诊断或医疗建议。

### 六项趣味指数的方向

趣味指数由多个五维偏好按固定权重组合而成。高低表示组合倾向，不代表单项维度一定同向；“老干部指数”和“求稳指数”采用不同权重。

- **少年感**：越高，越偏向探索新奇、接受风险、保持理想，也较少依赖稳定和长期确定性；越低，整体更偏熟悉稳妥，较少呈现这组探索冒险倾向。计算：探索新奇 × 40% + 风险胃口 × 25% + 理想主义 × 20% +（100 − 规划稳定）× 15%。
- **老干部指数**：越高，越偏向规划稳定、规避风险、选择熟悉的做法；规划稳定权重最大。越低，整体更偏变化与探索，较少呈现这组谨慎倾向。计算：规划稳定 × 45% +（100 − 风险胃口）× 30% +（100 − 探索新奇）× 25%。
- **上头指数**：越高，越偏向接受风险、主动探索并保留理想，不代表冲动程度或诊断；越低，整体更偏稳妥，较少呈现这组冒险探索倾向。计算：风险胃口 × 60% + 探索新奇 × 25% + 理想主义 × 15%。
- **折腾指数**：越高，越偏向探索新奇、追求自主，也更能接受风险；探索新奇权重最大。越低，整体更偏熟悉稳妥，较少呈现这组探索自主倾向。计算：探索新奇 × 65% + 自主倾向 × 20% + 风险胃口 × 15%。
- **求稳指数**：越高，越偏向规划稳定、规避风险、选择熟悉做法；规划稳定权重最大，比老干部指数更强调规划稳定、较少强调低探索。越低，整体更偏变化与冒险，较少呈现这组求稳倾向。计算：规划稳定 × 55% +（100 − 风险胃口）× 30% +（100 − 探索新奇）× 15%。
- **理想青年指数**：越高，越偏向理想、探索新奇和自主，理想主义权重最大，不代表实际年龄；越低，整体较少呈现这组理想探索倾向，也不代表年龄。计算：理想主义 × 55% + 探索新奇 × 25% + 自主倾向 × 20%。

这些年龄原型和映射属于测试内部的娱乐模型，未经真实年龄人群的大样本常模验证；结果不表示真实年龄、心理评估或对 AI 能力的判断。

## 隐私

答案与画像只在当前页面内存中处理；页面不会上传答案或结果，也不使用跟踪器。关闭或刷新页面后，本地内存中的作答不会保留。仓库中的截图是合成演示数据，不代表真实个人作答。

## 验证

运行评分模块测试：

```bash
node --test tests/scoring.test.mjs
```

Chromium 本地 smoke：桌面与 390px 手机视口均可展开 36 题/144 个单选项；空提交提示缺题并聚焦第一个未答题，逐题作答进度正确。个人和 AI 输入分别完成 36 个 A 均得到 20 岁原型结果并显示各自来源；折叠/重开保留选择，重置与编辑只影响对应来源结果。模拟题目文件 404 后，页面展示清晰错误并禁用复制与两种计分入口。六项趣味指数均显示高分方向，展开后可读低分含义与公式。浏览器拒绝剪贴板写入时，手动复制文本与 `题目.txt` 完全一致（36 个题干、144 个选项，无评分元数据）。手机页面无横向溢出，浏览器控制台无错误或警告。截图：`artifacts/personal-questionnaire-desktop.png`、`artifacts/personal-results-all-a-desktop.png`、`artifacts/personal-questionnaire-mobile.png`、`artifacts/personal-results-mobile.png`。
