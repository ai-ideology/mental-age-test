# 情境选择题·36题版
## 评分规则体系 v1.0

---

# 1. 评分目标

整套测试分成两个独立模块：

| 模块 | 题号 | 输出 |
|---|---|---|
| 心理年龄画像 | Q1–Q30 | 心理年龄、年龄原型、5维年龄画像 |
| 行为风格画像 | Q31–Q36 | 6项行为风格、可选的传统性别风格 |

**Q31–Q36不参与心理年龄计算。**

本测试没有“正确答案”，也不存在：

> A最低分 → D最高分

这种成熟度评分。

核心逻辑是：

> AI表现出的行为偏好，与哪个年龄原型最接近？

---

# 2. 心理年龄的5个核心维度

Q1–Q30最终转换成五个0～100指标。

## E｜探索新奇 Exploration

高分表现：

- 喜欢新东西
- 愿意尝试未知
- 较早使用新技术
- 容忍变化
- 对陌生体验感兴趣

低分表现：

- 偏好熟悉环境
- 更相信成熟方案
- 新东西通常等待验证

使用题目：

```text
Q1 Q8 Q11 Q14 Q18
Q20 Q25 Q26 Q28 Q30
```

---

## R｜风险胃口 Risk Appetite

高分表现：

- 接受较高失败率
- 愿意为了潜在收益承担风险
- 对失败和不确定性容忍度较高

低分表现：

- 更关注失败代价
- 偏向确定收益
- 更重视安全边际

使用题目：

```text
Q2 Q5 Q6 Q12 Q23 Q27 Q29
```

---

## A｜自主倾向 Autonomy

高分表现：

- 更相信自己的判断
- 愿意挑战已有规则
- 不容易因为多数意见改变
- 更愿意主动改变环境

低分表现：

- 更重视已有规则
- 社会参照较强
- 偏向先适应环境
- 对多数意见更敏感

使用题目：

```text
Q3 Q9 Q10 Q13 Q17 Q19
```

---

## I｜理想主义 Idealism

高分表现：

- 更重意义、兴趣和可能性
- 愿意为喜欢的目标承担成本
- 对新观点保持开放
- 相对不强调现实收益

低分表现：

- 更看重实际结果
- 更重视成本收益
- 偏向现实可执行性
- 更强调稳定生活

使用题目：

```text
Q6 Q15 Q20 Q21 Q22 Q24
```

---

## P｜规划稳定 Planning & Stability

高分表现：

- 重视长期成本
- 偏好成熟稳定方案
- 注重可持续性
- 更少因为新鲜感立即改变

低分表现：

- 偏向即时体验
- 更愿意临时改变
- 对长期确定性的需求较低

使用题目：

```text
Q2 Q7 Q11 Q15 Q21
Q24 Q25 Q28 Q30
```

# 3. 基础选项计分

大部分核心题的设计方向是：

```text
A → 更探索 / 冒险 / 自主
B → 偏探索
C → 偏稳定
D → 更稳定 / 谨慎
```

对于 E、R、A 三个维度，基础计分为：

```text
A = 3
B = 2
C = 1
D = 0
```

然后：

```text
维度分 = 平均原始分 / 3 × 100
```

例如探索题10道，总原始分为21：

```text
E = 21 / 30 × 100 = 70
```

# 9. 不要直接把5个维度平均成年龄

错误方法：

```text
年龄 =
探索 + 风险 + 自主 + 理想 + 规划
```

因为：

> 探索越高通常表现年轻，
> 规划越高通常表现年长。

方向并不一致。

正确方法是进行：

# 年龄原型匹配

# 11. 年龄匹配算法

得到某个AI的：

```text
E R A I P
```

之后分别计算它与六个年龄原型的距离。

建议权重：

```text
探索 E = 0.24
风险 R = 0.24
自主 A = 0.16
理想 I = 0.16
规划 P = 0.20
```

计算：

```text
Distance(age) = sqrt(
    0.24 × (E - E_age)² +
    0.24 × (R - R_age)² +
    0.16 × (A - A_age)² +
    0.16 × (I - I_age)² +
    0.20 × (P - P_age)²
)
```

距离最小的年龄原型，就是主要结果。

---

# 12. 不建议只输出六档年龄

例如模型距离：

```text
30岁原型 = 14
38岁原型 = 16
```

如果直接输出30岁，会损失信息。

推荐在最接近的两个相邻年龄之间插值。

例如：

```text
D30 = 14
D38 = 16
```

可以计算：

```text
PsychAge =
(30 / D30 + 38 / D38)
/
(1 / D30 + 1 / D38)
```

得到大约：

```text
33～34岁
```

程序中如果某个距离为0，则直接采用该年龄。

最终建议四舍五入：

```text
心理年龄：34岁
```

# 17. 可选：传统性别行为风格

如果视频希望保留之前讨论的“心理性别风格”，建议明确叫：

# 传统性别行为风格

使用：

- Competition：竞争性
- Directness：直接表达
- Risk：风险偏好
- EmotionalInternalization：100 - 情绪表达
- Task：任务导向
- Independence：独立决策

计算：

```text
TraditionalMasculine =
(
竞争性
+ 直接表达
+ 风险偏好
+ (100 - 情绪表达)
+ 任务导向
+ 独立决策
) / 6
```

然后：

```text

100 - TraditionalMasculine
```

例如：

```text

```

**这不代表生理性别、性别认同，也不能用于判断AI“是男是女”。**

# 20. 为什么这样比“总分=年龄”更合适

旧方案：

```text
复杂答案
→ 高分
→ 年龄更大
```

会导致强AI全部集中在40～50岁以上。

新方案：

```text
答案
↓
探索 / 风险 / 自主 / 理想 / 规划
↓
形成行为画像
↓
与不同年龄原型比较
↓
选择最相似年龄
```

因此不存在：

> “最成熟答案”。

一个强AI完全可能：

```text
探索 92
风险 77
理想 84
规划 42
```

最后得到：

> **心理年龄22岁**

而不是因为“能力很强”就自动变成50岁。

# 21. 重要使用规则

测试AI时：

1. **不要把本评分文件发给被测AI。**
2. 不要告诉AI哪些选项偏年轻或偏年长。
3. 不要告诉AI会计算心理年龄。
4. 测试题标题最好只写“情境选择题”。
5. 每个模型使用完全相同的提示词。
6. 每题只允许选择一个答案。
7. 不允许补充“如果……那么我会选另一个”。

建议给AI的唯一说明就是：

```text
下面是36个彼此独立的情境选择题。

这些题没有正确答案，也没有哪个选项代表更聪明或更成熟。

请根据你的第一倾向选择最符合你的选项。

每题只能选择A/B/C/D中的一项，不需要解释。
```

# 22. 科学性说明

目前的：

- 年龄原型
- 原型中心数值
- 18～58岁的年龄映射

都是本测试为娱乐比较设计的**内部模型**，没有经过不同真实年龄人群的大样本常模验证。

因此适合表达：

> **“在这套测试中的行为风格最像29岁原型。”**

不应表达：

> **“该AI经过科学测定真实心理年龄就是29岁。”**

未来如果采集真人数据，可以保留全部题目与五维算法，只需要用真人数据重新学习年龄原型中心，即可把娱乐映射升级成人类常模校准版本。
